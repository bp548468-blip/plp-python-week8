# Personal Mini-Toolkit - PLP Python Week 8 Final Project

## What My Toolkit Does
My Personal Mini-Toolkit is a menu-driven program with 3 useful tools in one place:
1. **Quick Calculator** - Adds, subtracts, multiplies and divides two numbers.
2. **To-Do List Manager** - Add, view and remove tasks. Tasks are stored in a list that changes while the program runs.
3. **Expense Tracker** - Add expenses, view them all, and see the total spent.
